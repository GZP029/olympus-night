# Olympus Night

A Greek night-sky theme for the Claude Code desktop and mobile apps: a deep navy background, marble-colored text, gold accents, serif headings and a still starfield with a small constellation and a gold Greek-key (meander) border along the top. The starfield is static, so it costs the GPU almost nothing once drawn. The terminal and editor integrations do not draw themes, so it only changes how the apps look.

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install olympus-night --marketplace GZP029/olympus-night
```

Answer `y` to add the marketplace, then pick a scope (user scope applies it to every project).

From a shell:

```bash
claude plugin install olympus-night --marketplace GZP029/olympus-night
```

Restart the Claude desktop app afterwards so new sessions pick up the theme.
